# 学生综合测评系统

面向信息管理系的学生综测项目。网页提供申报、证明材料上传、班级初审、辅导员复审、院系终审、结果公示和统计查询。后端通过 MySQL 账号和存储过程执行操作，沿用原设计的 13 个业务实体和 14 个主要联系。

## 在 Windows 打开演示

1. 将项目解压到可写目录。电脑需要安装 Python 3.11 或更新版本，以及 MySQL Server 8.4。
2. 双击 **启动演示.cmd**。首次运行会安装 Python 依赖并初始化独立演示库，通常需要等待片刻。
3. 浏览器会打开 **http://127.0.0.1:8000**。在「体验演示账号」点击所需角色即可进入。按 **Ctrl+C** 停止服务。

演示只在本机监听，自动选择一个空闲端口启动独立的 MySQL。数据保存在当前用户的 `%LOCALAPPDATA%\StudentAssessmentDemo`，关闭后再打开可以继续操作。想从头演示时，可将环境变量 `SA_DEMO_DIR` 指向一个新的空目录。若网页端口被占用，设置 `SA_WEB_PORT` 后重启。MySQL 安装在非默认位置时，设置 `SA_MYSQL_BIN` 指向 MySQL 8.4 的 `bin` 目录。

## 演示路线

- **直接看结果**。以学生登录，在「测评结果」查看 2025–2026 学年预置成绩 85.60 分、学年第 1 名。统计分析员可以查看并列排名、班级成绩分布和项目统计。
- **完整走一遍**。选择 2026–2027 学年，以学生身份建表、添加条目、上传材料并提交。用侧栏的「切换演示身份」依次进入班级初审、辅导员复审和院系终审；终审通过时填写核定分。可以在初审先驳回一条，再用学生账号撤回、修改和重提，观察审核轮次。
- **生成新结果**。终审完成后，用公示管理员结束申报并发布。切回学生账号即可看到本次测评结果。

演示账号和材料均为虚构。评分公式、等级线和并列排名口径见 [数据库使用说明](使用说明.md)。

## 接入已有 MySQL 库

已运行过建库脚本的用户，可以在 MySQL Workbench 中直接运行 `03_网页接口.sql` 一次。新库先运行 `01_创建数据库.sql`，需要虚构样例时运行 `02_演示数据.sql`，再运行 `03_网页接口.sql`。新学年、规则、人员和班级由管理员通过 SQL 配置。

业务人员使用各自的 MySQL 账号登录。先按 [数据库使用说明](使用说明.md) 绑定学生或审核人员并配置默认角色。公示和分析账号分别授予 `sa_publisher` 和 `sa_analyst`。示例授权命令如下，账号须已创建且已与学生记录绑定。

```sql
GRANT 'sa_student' TO 'sa_demo_s001'@'localhost';
SET DEFAULT ROLE 'sa_student' TO 'sa_demo_s001'@'localhost';
```

在项目目录安装依赖后启动普通模式。普通模式按用户输入的数据库账号验证身份。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:SA_MYSQL_HOST = "127.0.0.1"
$env:SA_MYSQL_PORT = "3306"
.\.venv\Scripts\python.exe app.py
```

当前版本面向本机课程演示。网页应用进程在内存中保存登录会话，重启后用户需要重新登录。正式部署需配置 HTTPS 和数据库 TLS（`SA_HTTPS=1`、`SA_MYSQL_TLS_CA`），并使用适合部署的 WSGI 服务。连接远程数据库时请使用可验证的 CA 证书。管理员账号与材料访问日志仍通过 MySQL 维护。

## 项目文件

| 文件 | 用途 |
| --- | --- |
| `01_创建数据库.sql` | 表结构、约束、评分、审核流程和权限 |
| `02_演示数据.sql` | 虚构历史学年和开放学年 |
| `03_网页接口.sql` | 网页所需的账号、草稿和学年接口 |
| `app.py`、`templates/`、`static/` | Flask 后端及响应式网页 |
| `demo.py`、`启动演示.cmd` | 独立演示库和启动入口 |
| `tests/test_workflow.py` | MySQL 与网页集成测试 |

安装依赖后，用 `python -m unittest discover -s tests -v` 运行测试。测试会新建并清理独立的 MySQL 目录，核验登录、上传和下载校验、越权拦截、驳回重提、三级审核、发布和重启后的结果。
